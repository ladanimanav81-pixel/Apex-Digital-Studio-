# Apex Digital Studio - Next-Gen UI/UX Business Website (v2)

A modern, responsive, and accessible business website featuring a Dark/Light adaptive theme system, Bento Grid architecture, interactive service filtering, and real-time form validation.

## Included Files
- `index.html` — Complete Single-Page Application (All-in-One HTML, CSS, JS, and SVG) ready to run instantly in any browser.
- `css/style.css` — Extracted stylesheet with Dark/Light CSS custom properties and responsive Bento Grid rules.
- `js/main.js` — Extracted JavaScript for theme switching, mobile navigation, category filtering, and form validation.
- `images/dashboard-mockup.svg` — High-craft vector analytics graphic.
